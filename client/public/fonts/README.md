# Local font assets

Inter and Poppins provide the existing local fallbacks and staff typography. The storefront uses Latin variable-font subsets of Cormorant Garamond, Playfair Display and Plus Jakarta Sans, served from this directory to avoid a render-blocking external stylesheet.

The storefront files were retrieved from the Google Fonts CSS service on 7 November 2026. Original SIL Open Font License files are retained beside the assets. Font family sources and licenses are maintained in the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl).
